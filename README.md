# Voltara

Plataforma de presentaciones con inteligencia artificial, flipbooks interactivos y analíticas avanzadas.

## 🚀 Características

### **Generación con IA**
- Crea presentaciones completas desde un prompt de texto
- Convierte documentos PDF en presentaciones interactivas automáticamente
- Modo de refinamiento iterativo para ajustar secciones específicas
- Modo Narrativa que genera estructura con arco dramático desde una idea

### **Flipbook Interactivo**
- Efectos realistas de paso de página 3D: Clásico, Suave, Curl, Magazine
- Agrega enlaces, videos y animaciones embebidas
- Comparte con enlace o código de incrustación
- Analíticas en vivo de visualizaciones

### **Analíticas Detalladas**
- Vistas totales, tiempo promedio por slide y tasa de completado
- Mapa de calor de engagement y espectadores en vivo
- Segmentación por dispositivos, ubicaciones y fuentes de tráfico
- Exportación de reportes

### **Diseñador Inteligente**
- Auto-balance de layout y verificación de identidad visual
- Puntuación de diseño con sugerencias de contraste, alineación y espaciado
- Corrección automática de elementos visuales
- Aplicación de paletas de color y tipografía

### **Infografías y Datos**
- 8 tipos: Estadística, Cronología, Geográfica, Comparativa, Proceso, Lista, Ranking, Relacional
- Formatos optimizados para redes sociales
- Visualización avanzada: mapas de árbol, gráficos de burbujas, mapas de calor
- Importación desde hojas de cálculo, CSV y API

### **Multiidioma**
- Soporte para 7 idiomas incluyendo 5 lenguas indígenas
- Traductor en vivo para toda la presentación
- Interfaz completamente localizada

### **Modo Presentación**
- Cronómetro, teleprompter y vista de expositor
- Asistente de IA que detecta temas cubiertos en tiempo real
- Encuestas en vivo con resultados instantáneos

### **Colaboración**
- Edición en tiempo real con indicadores de usuarios activos
- Sistema de comentarios y control de versiones
- Historial de cambios y notificaciones

### **Exportación**
- PDF de alta calidad listo para imprimir
- Archivo de presentación editable
- Video narrado con voz
- Enlace interactivo y sitio web
- Imágenes de alta resolución
